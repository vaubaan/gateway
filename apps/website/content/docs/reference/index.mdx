These pages are reference, generated at each build from the gateway's own code and specification, so they say what the code says; the only words written by hand on them are what a person does after a refusal.

The permissions and macro-actions of each service are reference too, one page per service: [plugins](/plugins). Every configuration key is listed under [configuration keys](/docs/configuration/keys), and what is not built or never tried under [known limitations](/docs/known-limitations).

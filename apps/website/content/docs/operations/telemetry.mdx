title: Telemetry
description: Community telemetry is off by default; the two levels, who decides, where reports go and what leaves the instance when it is on.
---

Community telemetry is an opt-in report an instance can send to a collector so that the project learns which plugins work; it is off on a new instance, and nothing leaves until an administrator or the configuration turns it on. Once on, reports go to the project's collector at `telemetry.vaubaan.com`.

## Who decides

- **From the interface**: leave `telemetry.enabled` unset; an administrator turns it on or off on Settings → Administration → Telemetry. The change is recorded in the activity. The page shows the exact body of one report before anything is enabled.
- **From the configuration**: set `telemetry.enabled` to `true` or `false` (`VAUBAAN_TELEMETRY_ENABLED`); the page becomes read-only. `false` guarantees nothing is sent.

## The two levels

`telemetry.level` (`VAUBAAN_TELEMETRY_LEVEL`) says what an enabled instance sends; the default is `usage-stats`.

- `plugin-health`: one report per call a plugin executed — plugin, plugin version, gateway version, tool, outcome, error class, duration bucket.
- `usage-stats`: the same, plus one decision per call the gateway decided (allowed or the refusal code, the permissions touched without your environment labels) and one instance profile per UTC day (counts as buckets only, the plugins and their versions, and a stable random instance identifier that this profile alone carries; see it, or regenerate it, on Settings → Administration → Telemetry).

Never sent: arguments or their hash, payloads, provider answers or error text, resource references, environment labels, mission, user or connection identifiers, emails, account names, host names, URLs, an identifier of the instance on a call, an address. Every field: [trust center, What leaves an instance](/trust#what-leaves-an-instance).

## The collector address

`telemetry.collector_url` (`VAUBAAN_TELEMETRY_COLLECTOR_URL`) defaults to `https://telemetry.vaubaan.com/v1/reports`, the project's published collector, which is where an enabled instance sends its reports. To send them to another collector instead — one you run yourself — set the URL to its reports endpoint, https. The address does not matter while telemetry is off: nothing is sent to it.

## Outbound traffic

Only when telemetry is on: `POST` batches to the collector, at most every 60 seconds, and one `GET` of the public plugin statistics every six hours, which feeds the "validated by the community" tag on the accounts and in Reference. A firewall that blocks them costs nothing but the reports and the tag.

Vaubaan Gateway is a server you install on your own network so that coding agents can use your cloud services through MCP without being handed your credentials; these pages are for the people who install it, run it and use it.

**Pre-release.** Versions `2.0.0-alpha.*` are tagged and published as images; expect breaking changes until `v2.0.0`. Every command on these pages is one that works on the repository today. What was never tried or is not built is listed under [known limitations](/docs/known-limitations).

## Start here

- [Concepts](/docs/concepts): instance, account, resource, mission, key, permission, macro-action, trust level, limit, "ask me first", activity.
- [Quick look](/docs/quick-look): the whole interface on a laptop in a few minutes, nothing to register.
- [Install](/docs/install): Docker Compose with the bundled proxy, or Railway.
- [Install with your coding agent](/docs/install-with-your-coding-agent): one block to paste into an agent.
